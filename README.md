## ⚡ Executive Profile

I am a **Systems & AI Engineer** and **3rd-Year Integrated M.Tech (Computer Science & Engineering)** student at **VIT-AP University**, focused on engineering production-grade software across deep learning, cryptographic security, autonomous space telemetry, and full-stack cloud ecosystems.

- 🧠 **AI & Computer Vision:** Designing and benchmarking **Vision Transformers (ViT, SAM)**, **FR-UNet**, and **Mixture-of-Experts (MoE)** architectures for medical vessel segmentation, multi-spectral satellite cloud removal, and automated code synthesis.
- 🔐 **Post-Quantum Security & CTFs:** Implementing **NIST FIPS 203 (ML-KEM)** and **FIPS 204 (ML-DSA)** cryptographic standards, crypto-agility middleware, and competing in offensive/defensive Capture The Flag (CTF) security operations.
- 🌐 **Full-Stack & Agentic Workflows:** Building low-latency web applications and **Model Context Protocol (MCP)** integrations powered by **React 19, TypeScript, FastAPI, Node.js**, and polyglot database engines (**MongoDB, Redis, Neo4j, MonetDB, SQL**).
- 🛰️ **Space-Tech & Embedded Hardware:** Developing lunar horizon ray-casting suites, planetary survival simulations, and physical IoT sensor arrays on **ESP32** and **Arduino** microcontrollers.
